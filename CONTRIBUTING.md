# Contributing to libélula

Thanks for helping! This is a skeleton, so the bar for contributions is: **does it keep the pattern clean and general** (not tied to one model/vendor/dataset)?

## Ways to help
- Add example model plugins (kept generic/placeholder — no proprietary weights or data).
- Add QC checks, orchestrator backends (Airflow/Prefect/Dagster examples), or container recipes.
- Improve docs.

## How
1. Fork + branch.
2. Keep changes small and focused; match the existing style.
3. `python examples/run_local.py` must still pass.
4. Open a PR describing what and why.

By contributing you agree your work is licensed under Apache-2.0.
